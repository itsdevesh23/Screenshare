# Frontend

React + Material UI frontend for the intranet inspection system.

## Run

On Windows PowerShell, use `npm.cmd` if script execution blocks `npm`:

```bash
npm.cmd install
npm.cmd run dev
```

The dev server runs at:

```text
http://localhost:5173
```

Seed users from the backend:

```text
sbu1 / password
inspector1 / password
```
